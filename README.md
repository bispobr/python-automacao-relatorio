# python-automacao-relatorio

Este repositório contém uma automação simples desenvolvida para um site. A automação utiliza o navegador chrome para acessar o site, realizar o login de forma automatica e inicia o download de todos os relatórios que se encontram na página. Os dados são então armazenados em uma pasta especifica. A automação foi implementada em Python utilizando algumas bibliotecas listadas na secção inicial.

## Como Usar

1. Clone o repositório:

```bash
git https://github.com/bispobr/python-automacao-relatorio.git
```
2. Defina o local de salvamento do download
3. execute o arquivo app.py
